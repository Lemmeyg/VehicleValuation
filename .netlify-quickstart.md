# Netlify Cost Optimization - Quick Start

## 🎯 Immediate Action (5 minutes)

### Step 1: Disable Dev Auto-Deploys
1. Go to [Netlify Dashboard](https://app.netlify.com)
2. Select your site
3. **Site Settings** → **Build & Deploy** → **Continuous Deployment**
4. Scroll to **Branch deploys**
5. Click **Edit settings**
6. Select **"Let me choose which branches to deploy"**
7. **Only check**: ✅ `main` and ✅ `staging`
8. **Uncheck**: ❌ `dev`
9. Click **Save**

**Result**: ~50-70% fewer builds instantly! 🎉

---

## 🔄 New Workflow

### Working on Dev Branch
```bash
# Commit as normal - no builds triggered ✅
git checkout dev
git add .
git commit -m "feat: add new feature"
git push origin dev  # ← No Netlify build!

# Test locally (runs like Netlify environment)
npm run dev
# or
netlify dev  # If you have CLI installed
```

### When You Need to Deploy Dev
**Option 1: Netlify UI** (easiest)
1. Go to Netlify Dashboard → Deploys
2. Click **"Trigger deploy"** → **"Deploy site"**
3. Wait ~1-2 minutes

**Option 2: Merge to Staging** (recommended for testing)
```bash
git checkout staging
git merge dev
git push origin staging  # ← Auto-builds staging!
```

**Option 3: Netlify CLI** (fastest)
```bash
netlify deploy  # Preview deploy
netlify deploy --prod  # Production deploy (use carefully!)
```

## 💡 Skip Deploys for Minor Changes

Add `[skip-deploy]` to commit messages:
```bash
# These will skip builds even on staging/main
git commit -m "docs: update README [skip-deploy]"
git commit -m "chore: fix typo [skip-deploy]"
git commit -m "style: format code [skip-deploy]"

# Regular commits (will build normally)
git commit -m "feat: add user authentication"
git commit -m "fix: resolve login bug"
```

## 🆘 Quick Troubleshooting

**"I need to test dev urgently!"**
→ Use Netlify UI "Trigger deploy" button (30 seconds)

**"Staging isn't auto-deploying"**
→ Check that `staging` is enabled in Branch deploys settings

**"How do I test without deploying?"**
→ Run `npm run dev` or `netlify dev` locally

**"I want to re-enable dev auto-deploys temporarily"**
→ Netlify UI → Settings → Enable `dev` branch → Save
→ Remember to disable again when done!
